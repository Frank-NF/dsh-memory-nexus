# dsh-memory-nexus

[中文](./README.zh-CN.md) | English

DSH integrated memory and context management enhancement plugin.

## Features

- Four-layer memory system (L1-L4)
- Context compression, trimming, freezing
- Prompt orchestration
- Input box UI buttons

## Installation

```sh
dsh plugin --profile web add github:Frank-NF/dsh-memory-nexus
```
